# @arm64js/protocol

The protocol between the [arm64js SDK](https://www.npmjs.com/package/arm64js) and the arm64js engine runtime it loads from `cdn.arm64js.com`: the `Host` API types, the frame handshake, the RPC messages, the RPC client and the error codes.

You don't need to install this package yourself, `arm64js` depends on it.
